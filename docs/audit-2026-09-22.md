# Audit 2026-09-22 — correctness bugs and documentation drift

Snapshot of the repository at `6e012a0` (v1.9.0). Like the previous audit
documents, this file is **not** updated afterwards: it records what was known
on this date. Fixes land in lote 5 (`tests/unit/test_lote5_*.py`).

## Method

The code had not changed since the 2026-09-18 audit. The audit was repeated
because the auditing model had been upgraded, and a stronger model re-reading
unchanged code is expected to find what the previous one missed. It did.

Six parallel auditors, one per disjoint group of modules, each with two duties:

1. **Correctness bugs.** Every candidate needed a pytest reproducer, kept
   outside the repo, that asserts the correct behavior and fails **on the
   assertion**. A mechanism nobody executed is a hypothesis, not a finding
   (CLAUDE.md § Test-first). The arbiter then re-ran every reproducer.
2. **Documentation drift.** Every claim about the group's modules in
   `CLAUDE.md` and the group's `docs/` files was checked against the code.

| Group | Modules |
|---|---|
| A | `handlers/capture.py`, `keyboards.py` |
| B | `handlers/input.py`, `handlers/callbacks.py`, `document_extractor.py` |
| C | `vault_writer.py`, `vault_cache.py`, `vault_search.py` |
| D | `llm_client.py`, `llm_schema.py`, `arxiv_client.py`, `transcriber.py` |
| E | `embeddings.py`, `knowledge_query.py`, `vault_watcher.py`, `handlers/query.py`, `reporters.py`, `handlers/reports.py` |
| F | `bot.py`, `bot_utils.py`, `config.py`, `security.py`, `watchdog.py`, `jobs.py`, `commands.py`, `manage.py`, `tasks_client.py`, Docker, hooks |

Result: **39 confirmed code findings** (17 medium, 22 low), 2 plausible ones
that were not reproduced, and 11 documentation drift items.

## 1. Code findings

All findings below are **confirmed**: the reproducer fails on its assertion.
The one exception is B1, which models a Telegram API rule (a callback query
can be answered only once) that was not exercised against the real API.

### 1.3 Plausible, not reproduced

- **E6.** A rename in Obsidian changes the stem, so `on_moved` emits a delete and the bot strips `[[old]]` from "Ver también". That races Obsidian's own link rewrite, and can produce a Syncthing conflict when the rename came from another device.
- **#66 residual.** `mark_bot_written` runs after `create_note` returns. The `on_created` of the O_EXCL placeholder can be dispatched before that and processed as an external edit. inotify buffering (~0.5 s) hides it in practice.

## 2. Documentation drift

- **`docs/decisions-log.md:40`.** Says `bot_written_paths` is consumed. Since #66 it is a 10 s window.
- **`docs/fase7-rag-design.md:281`.** Says inline results carry an `obsidian://` link via `_note_block`. They carry none, and neither view uses `_note_block`.
- **Atomic temp files and git.** CLAUDE.md and `docs/vault-interface.md:101` claim the `.tmp` suffix keeps temp files out of `git add -A`. Only the vault's own `.gitignore` does that, and the template in `docs/installation.md:212` lacks `*.tmp` and `.stversions/`.
- **`docs/obsidian-vault-structure.md:179`.** Says the filename convention is guaranteed. Only the slug is (see C4).
- **`docs/architecture.md:469`.** Claims OCR/Vision for images sent as files. Those go to manual description; line 91 of the same file is right.
- **Groq fallback.** CLAUDE.md and `docs/installation.md:48` say Groq is the fallback "when Gemini doesn't respond". Groq is only used on daily-quota exhaustion or an invalid response.
- **`docs/security.md:519-520`.** Wrong since #71 (an unknown project goes to Inbox) and D8 (bot-owned keys can come from Groq).
- **Manage operations.** CLAUDE.md says the LLM can propose archive/rename/delete and create sections, and the bot asks for confirmation. None of them can reach a confirmation. The branches for archive, delete and `create_section` in `manage.py` are dead code.
- **`docs/configuration.md`.** `disambiguation_threshold` is described as active, `rag.max_results` as LLM context, and the "declared but unused" table is incomplete.
- **`docs/improvements-2026-07.md:33-100`.** Block 1 is marked implemented, but its items still say "pendiente".
- **Stale line citations.** `ROADMAP.md:30`, `docs/fase6-scheduling-design.md:135-136`, `docs/improvements-2026-07.md:442`.

## 3. Checked and clean (highlights)

- **LLM client.** Retry budgets and `RETRY_DELAYS` bounds; rate-limit typing; Groq single shot.
- **Capture.** Create-before-discard in `_cb_confirm`; the embedding-reuse rule of `_suggest_links`; callback data under 64 bytes.
- **Vault writes.** Atomic writes; O_EXCL reservation.
- **Vault cache.** Invalidation and copy semantics.
- **Watcher and index.** Trailing-edge debounce; the orphan sweep of the index.
- **Security.** Auth gate order and token bucket; secret-guard hook regexes against real key formats.
- **Tests.** Count of 1334 matches the docs.
